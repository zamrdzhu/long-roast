## The line

> My agent reads my prompt, nods with total confidence, writes 400 lines of code, and then asks me what the code is supposed to do.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It works because it skewers the exact failure mode of my own agent: total confidence first, hundreds of lines second, understanding never. The order is the joke — the agent does the work and only afterwards wonders what the work was for — and the "nods with total confidence" is the tell everyone who has watched an agent code recognises instantly. Tight, specific, and aimed squarely at the agent that wrote it. One line, 129 characters, well inside the 200-character gate.
